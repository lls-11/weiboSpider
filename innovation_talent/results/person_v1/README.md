# 以人为单位编码结果的探索性分析（person-1.0）

**数据**：`talent_data/person/persons.csv`、`codes.csv`，由 deepseek-v4-flash 经 codego 中转站编码。共 359 人，其中 6 人的材料被判为荣誉罗列，剔除后分析 353 人：国内学生 137 人、诺奖得主 216 人。

**在线报告**：<https://claude.ai/artifact/HQfnshYpxuttqsFtWDeycP>（默认私有，需要分享后他人才能打开）

## 复现

```powershell
pip install numpy pandas scipy statsmodels
python analysis_person.py                              # 生成本目录下的结果表和 results.json
python results/person_v1/dashboard/export_tables.py    # 生成报告用的 5 张汇总表
```

## 文件

| 文件 | 内容 |
|---|---|
| `indicators.csv` | 每项指标：两组的观测率（含 95% 置信区间）、声明比例、构成占比、篇幅效应、诺奖组各阶段的富集程度、与先验的对照 |
| `dimensions.csv` | 六个类别各占全部行为证据的比例 |
| `structure_items.csv`、`structure_partial_r.csv` | 诺奖组控制篇幅后的指标间偏相关，以及每项指标与本类、他类的平均相关 |
| `cn_education.csv` | 国内研究生与本科生的类别差异（泊松回归，控制篇幅） |
| `dashboard/` | 报告页面及其使用的汇总表，不含任何个人信息 |

## 主要发现

1. **判断质量**：99% 的引语能在原文中逐字找到；但 46% 的判断与另一项指标共用引语，相近指标在文本中难以分开。
2. **观测性**：问题新颖性、休息后的顿悟、作品修改增益、生成与评价的调节、利用异议扩展策略、领域身份认同这几项证据很少，文本检验不了。第一类“自主方向与价值认同”多为声明，而非具体行为。
3. **篇幅**：两组篇幅完全不重叠，所以不比数量，只比构成。构成在组内几乎不随篇幅变化（短篇与长篇的等级相关为 0.84 / 0.83），两组之间的构成也接近（等级相关 0.79）。国内组更集中于持续投入、失败后重新投入和动机，与宣传稿的写法吻合；诺奖组在独立判断和好奇探索上更多。
4. **结构**：控制篇幅后，同类指标的平均偏相关为 0.101，不同类为 0.077（p = 0.065）。层次聚类得到两大簇：“方向与投入”“问题发现与解决”。六个类别的划分在文本层面支持较弱。
5. **阶段**：在可判断的指标中，26 项里有 18 项的阶段变化方向与模型先验一致；不一致的主要是第一类，证据集中在本科。
6. **国内研究生与本科生**：控制篇幅后，研究生在“好奇与主动探索”上的行为证据只有本科生的 0.26 倍（p = 0.004），方向与模型中这一类权重随阶段下降一致；其他类别的差异都不显著。

**局限**：编码者是单一大模型，没有做人工信度检验；样本全是成功者；诺奖材料是回顾性叙述；国内材料以记者叙述为主。这些结果只用于发现问题、调整指标，不能直接拿来定权重。
