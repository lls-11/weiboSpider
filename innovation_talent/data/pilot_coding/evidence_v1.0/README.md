## 发现

1. **各篇的可编码内容差距很大**，取决于文本有没有写过程，而不在篇幅。张如范的专访写了三个完整的科研事件：挂载失败后改做子问题、数据分析建立生长模型、自制测量装置。同等篇幅的 Boyle 自传是一份履历；Marshall 的访谈页只转录了获奖当天的电话，正式访谈是视频，没有文字稿。
2. **诺奖访谈要先筛一遍**：300 篇访谈中有 158 篇含获奖当天的电话访谈，这部分内容多是获奖感言。建议批量运行前先剔除只有电话访谈和视频简介的页面，或者只编正式访谈的文字稿。
3. **国内报道以记者叙述为主**：张如范的 14 条支持证据中，11 条的归因是“记者或传记作者”，本人直接引语多是总结性的话（“科研的进步，大多来自坚持和积累”）。手册要求单独记录 attribution，这次试编证明确有必要。
4. **发现并修正了一处切分错误**：高焕昂那一段原来混进了下一位答辩人周汝赟的全文，因为同一篇文章混用了“院系—姓名”和“姓名 院系”两种标题格式。`segment.py` 已修正，分析集由 124 段变为 125 段（周汝赟单独成段）。
5. **需要课题组裁定的边界**（已写在相应证据的 limitation 中）：
   - 张如范 E006：偶然发现转为测量方法，记 T12 还是 T11b？
   - 张如范 E004：导师给总课题、本人提出子问题，按手册记 T05，是否认可？
   - 邓禹 E003：导师给出理论判断后本人继续实验，按排除条件记 T14“不确定”；
   - Boyle E003/E004：原文只写了事件年份，`age_at_event` 填了“28—29岁”这样的区间。手册写的是“凭明确生日与事件日期计算”，只有年份时是否允许给区间？
   - 邓禹 E005：“少休息半小时处理学生工作”安排的是学生工作时间，算不算 T06a 的学习调节？
