# 创新人才识别模型：公开文本数据的初步验证方案

本文说明如何用公开文本对《创新人才识别模型（TAD 四阶段版）》做初步验证，以及本文件夹中 `talent_corpus` 模块的使用方法。编码手册全文（33 项指标 × 4 个阶段的行为锚点）见 [codebook.md](codebook.md)，由 `talent_corpus/data/codebook.json` 生成。

## 一、能验证什么，不能验证什么

公开文本是回顾性行为叙事，适合检验：

- **叙事显著性**：各项指标在人物成长叙事中出现的频率，以及这种频率是否随发展阶段变化；
- **阶段相关度先验的方向**：模型假设“好奇与主动探索”随阶段下降、“独立判断”“自主方向”随阶段上升，科学家自传按人生时期切分后可以检查方向是否一致；
- **已知组差异**：创新型与非创新型获奖学生、学生与科学家同期（本科到博士）叙事的画像差异；
- **本土化特征**：国内文本与诺贝尔奖获得者文本中哪些成长路径、动机表述更常见。

公开文本不能检验：

- **预测效度**：文本里只有成功者，没有对照组的长期结局（幸存者偏差）；
- **实验任务类指标**：潜伏抑制（C12）、注意范围（C13）、干扰下的信息筛选（C15）、语义网络结构（C17）需要实验或测验，文本编码一律记为缺失；
- **常模百分位**：模型的得分是同龄常模百分位，文本编码给出的是“阶段锚点”，属于标准参照，两者不能直接等同。

## 二、与七条建议的对应

| 建议 | 在本方案中的做法 |
|---|---|
| (1) 每阶段指标用文字描述 | 编码手册为 33 项指标各写了 4 个阶段的行为锚点，并给出每个阶段在文本中的典型特征、外部评价来源和典型成果（`codebook.json` 的 `stages` 与 `anchors`）。锚点同时可作为德尔菲专家评定的材料。 |
| (2) 先聚焦大学生阶段 | 主样本为本专科生和研究生；默认阶段判定：本专科 2、硕士 2.5、博士 3。科学家样本用于提供阶段 3–4 的原型和阶段形状的对照。 |
| (4) 校标文本来源 | 《人民日报》五四前后刊登的国家奖学金获奖学生代表名录（本专科 100 人 + 研究生 100 人），再按姓名与院校检索高校新闻网与公众号的长篇报道。 |
| (5) 文本还原度与心理测量 | 每项指标标注“文本可观测性”（高 10 项、中 15 项、低 4 项、不可 4 项）。默认只用高、中两档计分；词频只作辅助特征，不替代指标得分。 |
| (6) 校准先验、真实原型、本土特征 | 阶段显著性分析与模型的阶段相关度、类别 × 阶段权重逐项比较；分析结果按 Excel《学生得分》版式导出，可替换虚构的学生甲乙丙丁；8 个本土化候选编码与模型未覆盖行为的归纳编码（NEW）。 |
| (7) 刻板叙事与样本分类 | 只编码具体事件：每条证据须引用原句并标注证据质量（1 概括、2 具体事件、3 事件 + 可核验结果），质量 1 不计分；口号句单独统计；先按成就类型把获奖学生分为科研、竞赛、成果转化、学业、服务、组织、文体、自强等类别，只有前三类计为创新型。 |

## 三、样本与数据来源

### 3.1 主样本：国家奖学金获奖学生代表

《人民日报》每年五四前后刊登两份名录：5 月 4 日本专科生（另有中职生名录，默认不纳入），5 月 5 日研究生，每份 100 人，每人附简短事迹。电子版地址有新旧两种格式，程序都支持：

- 新版：`https://paper.people.com.cn/rmrb/pc/content/202605/04/content_30154802.html`
- 旧版：`https://paper.people.com.cn/rmrb/html/2024-05/04/nw.D110000renmrb_20240504_1-06.htm`

取 2019–2026 年约可得 1,600 人。名录条目是统一格式的短文本，作为补充长文本的检索入口，并用于初步分类。

**补充长文本**：每人用姓名 + 院校检索高校新闻网、学院网站、官方公众号的专访和事迹报道。检索引擎的自动抓取不稳定且有服务条款限制，本方案采用半自动方式：程序生成检索工作表（每人一行，附百度、必应、搜狗微信检索链接），研究助理把找到的文章地址填入表中，再由程序抓取正文。微信文章常有访问验证，可在浏览器中“另存为网页”后批量解析。

### 3.2 原型样本：科学家

| 来源 | 文本类型 | 用途 | 获取方式 |
|---|---|---|---|
| 诺贝尔奖官网（物理、化学、生理学或医学） | 获奖时撰写的自传（Biographical）、晚宴致辞、访谈、讲座 | 自传覆盖童年到获奖，最适合按人生时期切分做阶段分析 | 官方 API v2.1 列出获奖者，程序抓取各页面 |
| 美国物理联合会（AIP）口述史 | 1,000 余篇物理学家、天文学家访谈全文 | 访谈通常从童年和求学经历谈起，阶段信息比自传更完整 | 网站可公开阅读；转载和引用需书面许可，只做内部编码分析 |
| 中国科协“老科学家学术成长资料采集工程” | 学术成长资料、口述与传记（截至 2026 年已启动约 750 位科学家） | 本土科学家原型，用于本土化特征比较 | 主要为出版物与馆藏，需人工整理录入 |
| 国家最高科学技术奖获得者、两院院士的人物通讯 | 新华社、《人民日报》、科学网等报道 | 本土阶段 4 原型 | 用 `articles` 子命令按 URL 清单抓取 |

### 3.3 其他可采集来源（按与本研究的相关度排序）

| 来源 | 对应阶段 | 价值 | 注意事项 |
|---|---|---|---|
| 中国大学生年度人物（教育部、人民日报社指导，2005 年起每年 10 人及提名） | 2–3 | 全国层面的高选拔样本，事迹较长 | 与国奖样本有重叠，需去重 |
| 高校本科生特等奖学金答辩与报道（如清华特奖） | 2–3 | 答辩材料常含研究过程、失败与调整等细节 | 各校体例不同 |
| 中国青年五四奖章、挑战杯与中国国际大学生创新大赛获奖团队报道 | 2–3 | 创新型对照组，项目过程描写较多 | 团队报道需区分个人行为 |
| 科学探索奖、未来科学大奖获奖人访谈与演讲 | 3–4 | 青年科学家的成长自述 | 多为视频，需转写 |
| 本仓库的微博爬虫 | 2–3 | 高校官方微博、团委账号发布的事迹微博及其头条文章；学生本人账号的第一人称表述 | 正文较短，主要用作长文入口；需要配置 cookie |

### 3.4 微博数据的用法

本仓库原有的 `weibo_spider` 按账号抓取微博。把高校官方微博、团委、中国大学生在线等账号的 user_id 写入 `user_id_list`（查找方法见 [userid.md](../../docs/userid.md)）运行后，用 `talent_corpus weibo` 按关键词和名录姓名筛选，并把其中的头条文章地址交给 `articles` 抓取。

## 四、编码方案

每篇文本先分句编号，再由编码员（人工或大模型）按编码手册逐项判断。每条编码包括：

- **指标**：编码时可选可观测性为高、中、低的 29 项；计分默认只用高、中两档的 25 项（`analyze --include-low` 纳入低档）；
- **阶段锚点 anchor_stage**：行为最接近的阶段锚点（1–4），与人物当时的年龄无关；
- **证据质量 evidence_quality**：1 概括陈述或评价语，2 具体事件，3 具体事件 + 可核验结果；
- **证据**：句子编号 + 逐字引文 + 人生时期（学前小学、中学、本科、研究生、博士后、独立研究期）+ 叙述归属（本人自述、叙述者转述、他人评价）。

几条关键约定：

- 未提及的指标保持缺失，不记零分，与模型的缺失值规则一致；
- 宣传文本的作者通常不是人物本人，用词风格反映作者，因此不对记者稿做词频、语义网络等指标推断；第一人称文本（自传、访谈、引语）单独标注，可做敏感性分析；
- 熬夜、少睡等叙述不作为持续投入的证据，单独记为本土化编码 L06；
- 大模型给出的每条引文都由程序核对：引文必须逐字出现在所引句子中，找不到的引文删除，没有有效引文的编码整条删除。

## 五、分析计划

1. **描述统计**：各语料组的事件句比例、口号句比例、第一人称比例；各指标出现率。用来判断哪些来源的信息量足够。
2. **样本分类**：规则分类与大模型分类各做一次，不一致的样本人工复核。后续分析只在分组内或分组之间比较。
3. **已知组比较**：创新型与非创新型学生在六类得分和各指标出现率上的差异（Mann–Whitney U、Cliff's δ、两比例检验）。若模型有效，创新型学生在第 2、4、5、6 类上应更突出。
4. **阶段先验校准**：把科学家叙事中的证据按人生时期归入 TAD 阶段，计算各指标在各阶段叙事中的出现率，与模型的阶段相关度比较：
   - 方向一致率：经验斜率与先验斜率同号的指标比例；
   - 逐指标的 Spearman 相关，以及合并全部计分指标 × 4 阶段的形状相关；
   - 类别层面：各阶段证据在六类之间的分布与类别 × 阶段权重对照。

   方向不一致或差异较大的指标作为德尔菲第一轮讨论的重点，而不是直接改权重：出现率反映叙事习惯（自传更多写成年后的研究），不等于预测力。
5. **学生与科学家同期比较**：只取科学家本科至博士后阶段（P2–P4）的证据，与创新型学生比较，看学生画像与科学家早期画像的差距在哪些类别。
6. **本土化特征**：比较国内学生、国内科学家、诺贝尔奖获得者三组的本土化编码出现率；汇总 NEW 标签，归纳模型未覆盖的行为。
7. **编码信度**：分层抽取 15%–20% 文档双人独立编码，指标出现与否的 kappa 达到 0.6、阶段锚点的加权 kappa 达到 0.7 后再全量编码；同时计算大模型与人工编码的一致性，决定大模型编码能否替代第二编码员。
8. **真实原型**：从各阶段选出覆盖率较高、类型清晰的人物，按《学生得分》版式导出得分，替换模型演示中的虚构学生。

关于覆盖率：文本只能观测部分指标，覆盖率会远低于模型 60% 的提示线。这是数据来源决定的，分析时以六维画像和单项出现率为主，综合参考分只作参考。

## 六、操作步骤

```bash
cd innovation_talent                        # 以下命令均在本文件夹内运行
pip install -r ../requirements.txt
pip install -r talent_corpus/requirements.txt   # 编码与导出 Excel 需要

# 1. 名录（2019–2026 年 5 月 4–5 日，可用 --window 调整），--dump-raw 保存原文用于核对条目切分
python3 -m talent_corpus rmrb --years 2019-2026 --dump-raw talent_data/rmrb_raw.jsonl

# 2. 检索工作表 → 研究助理填写 url 列 → 抓取正文
python3 -m talent_corpus search-sheet
python3 -m talent_corpus articles --urls talent_data/search_sheet.csv
python3 -m talent_corpus articles --local-dir 保存的网页目录   # 微信文章人工保存后解析

# 3. 诺贝尔奖获得者（物理、化学、医学）
python3 -m talent_corpus nobel --categories phy,che,med

# 4. 可选：微博（先在仓库根目录运行 python3 -m weibo_spider，结果在 ../weibo）
python3 -m talent_corpus weibo --weibo-dir ../weibo --entries talent_data/raw/rmrb.jsonl

# 5. 预处理、样本分类、词典特征
python3 -m talent_corpus prepare
python3 -m talent_corpus classify
python3 -m talent_corpus lexical

# 6. 人工编码样本（先做，用于检验信度和校准大模型）
python3 -m talent_corpus human-export --frac 0.2
python3 -m talent_corpus human-import --codes 编码员A.csv --coder human:A
python3 -m talent_corpus human-import --codes 编码员B.csv --coder human:B

# 7. 大模型编码：先试跑 10 篇检查结果，再全量；--batch-submit 走批量接口，费用减半
export ANTHROPIC_API_KEY=...
python3 -m talent_corpus code --limit 10
python3 -m talent_corpus code --batch-submit
python3 -m talent_corpus code --batch-collect <batch_id>

# 8. 分析
python3 -m talent_corpus analyze --coder claude-opus-5-5 --reliability human:A,claude-opus-5-5
```

`analyze` 在 `talent_data/analysis/` 下输出 CSV 与 `analysis.xlsx`，包括：人物、学生得分格式、六维画像、阶段显著性（指标、类别）、创新型与非创新型比较、科学家同期与创新型学生比较、本土化编码、新增编码标签、刻板叙事、编码一致性。

大模型编码默认使用 Claude Opus 5.5（effort 为 medium），编码手册放在系统提示中并启用提示缓存；同步模式开启服务端拒答回退（`fallbacks: "default"`），批量模式不支持该参数，被拒的文档会记为错误，可再用同步模式补跑。

## 七、局限与合规

**方法局限**

- 幸存者偏差：样本都是获奖者，只能比较组间差异和叙事形状，不能估计预测效度；
- 宣传框架：国奖事迹和人物通讯有示范目的，倾向于突出坚持、奉献和国家需要，本土化编码的出现率首先反映文体；
- 回顾偏差：顿悟、坚持等故事在回忆中容易被美化，相关指标的可观测性定为中或低；
- 中英文本差异：诺贝尔奖文本为英文自传，国内文本多为第三人称报道，两类文本在第一人称比例上本来就不同，比较时需控制叙述归属；
- 大模型编码偏差：必须用人工双编码样本检验，一致性不达标的指标不进入分析。

**合规与伦理**

- 抓取默认遵守 robots.txt，同一站点请求间隔 2–4 秒，原始网页本地缓存，避免重复请求；
- 微信公众号文章按平台规则人工保存，不批量绕过验证；
- 诺贝尔奖官网与 AIP 口述史的内容有版权，只做内部编码分析，不公开再分发原文；
- 名录中的姓名和院校虽为公开信息，研究数据仍应安全存放，报告中使用编号，不对个人做公开评价；
- 分析结果只用于检验模型，不用于对具体学生下结论。
