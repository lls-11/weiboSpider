# 分析方案：person 级 C01–C33 编码数据（359 人）

本文只讨论**已经拿到手的数据**怎么分析：`talent_data/person/persons.csv`（每人一行）、`codes.csv`（每条判断一行）、`runs.jsonl`（原始调用）。它和 `docs/research_design.md` 里那套 T01–T14「证据锚点 + 证据质量」方案是两代不同的工具，不要混用（见文末第 10 节）。

## 0. 一句话结论

**能做的**：指标在叙事中的**出现率**、**阶段分布**、**文体效应**、**组内差异**（学科、学历、获奖等级、材料类型），以及「学生在本科/研究生阶段表现出来的行为」与「科学家回顾自己本科/研究生阶段的行为」的对比。

**不能做的**：① 学生的创新能力 vs 科学家的创新能力；② 预测效度（没有非获奖对照组）；③ 综合能力分（覆盖率太低）。

原因见第 2 节的三条先导诊断——**两组文本量几乎不重叠，任何人均计数比较都是长度伪影**。

## 1. 数据现状

| 项目 | 内容 |
|---|---|
| 单位 | 人（person_id），359 人 = 国内学生 143 + 诺贝尔奖得主 216 |
| 材料 | 401 篇文档，一人 1—2 篇；国内为新闻/通讯/第一人称，诺奖为自传 + 深度访谈 |
| 模型输出 | `text_type`（过程叙述/荣誉罗列）、`education`、`discipline`、`gender`、`n_events`、`codes[]`（33 项指标，各带 level 1/2、stage、quote、verified、shared_quote） |
| 程序变量 | `chars`、`n_texts`、`source_types`、`award_level`、`crit_*`（论文/专利/奖项）、`cliche_ratio`、`first_person_share`、`honor_sentences_removed`、`in_rmrb_list` |
| 判断总数 | 3550 条（国内 595 条左右 + 诺奖其余） |
| 缺失 | 无人工双编码；无 T01–T14 证据级编码；无对照组；C12/C13/C15/C17 按设计不编码 |

## 2. 先导诊断：三个必须先知道的事实

**① 指标条数主要由文本长度决定**

- `r(log 字数, 指标数) = 0.805`；
- 文本量分布几乎不重叠：国内 98—4466 字（中位 720），诺奖 6504—117237 字（中位 26006），唯一重叠带里只有 **1 位**诺奖得主。

**② 一旦按长度归一化，「组间差异」的方向就翻转**

| | 国内学生 | 诺奖 |
|---|---|---|
| 人均指标（原始） | 4.14 | 13.53 |
| 每千字指标（中位） | **4.65** | **0.50** |

也就是说：原始差额是「诺奖文本长 36 倍」造成的；按每千字算，**国内学生的行为密度反而高 9 倍**（因为通讯稿句句都是具体事件）。两个数都不能当「能力」读。

负二项回归把组效应估成 IRR≈3.3（同等长度下诺奖更高），但这依赖对 720 字的诺奖文本外推，**没有共同支撑域，模型不可信**。结论：**不要做「学生 vs 诺奖」的人均指标比较**。

**③ 文体变量比组别更能预测指标数**

| 变量 | 与指标数的 Spearman ρ |
|---|---|
| 删去的荣誉清单句数 | **−0.62** |
| 第一人称比例 | **+0.62** |
| 套话句比例 | −0.32 |
| 材料篇数 | +0.16 |

**材料本身写了什么**（过程 vs 荣誉、本人视角 vs 记者转述）比「是谁」更有解释力。分析中必须把文体作为协变量或分层变量，不能只放组别。

**④ 低信息量个案集中在一侧**：15 人零指标全部是国内学生，36 人只有 1—2 项。这些不是随机缺失，与材料类型强相关，需要显式建模或敏感性分析。

## 3. 四条分析原则

1. **以出现率为主，以计数为辅**：主表报「该指标是否出现」（0/1）与「每千字率」，人均条数只作描述，并在脚注写明与文本量的 r=0.81。
2. **每个组间比较都带文体协变量**：`log(chars)`、`text_type`、`first_person_share`、材料篇数。报告「同等文本量/同等文体下」的效应。
3. **双计数口径并列**：`n_behavior` / `n_behavior_dedup` 各跑一遍主分析（去重口径只合并逐字相同的引语，影响约 −6%）。
4. **先信度、后推论**：人工双编码没做之前，所有结论都标为「机械编码结果，待信度检验」。

## 4. 六个分析问题

### RQ1 叙事显著性：33 项指标在两组材料中各自多常出现？

- **单位**：人 × 指标（0/1，行为级 level 2 为主口径；level 1 单列）。
- **模型**：`logit(P(指标出现)) ~ 指标 + 组 + 指标×组 + log(chars) + text_type + (1|学科)`，或逐指标各跑一个 logistic。
- **输出**：表 1（指标 × 组：出现率、OR、95%CI、FDR 校正 q）；图 1（33 项指标的组间 OR 森林图）。
- **看什么**：OR 的**分布**而非单个显著项；哪些指标在两组都稀少（→ 文本不可观测，参考性低）。

### RQ2 阶段结构：指标出现在人生的哪个阶段？

- **单位**：判断（3550 条，带 stage：中学及以前 / 本科 / 研究生 / 工作后 / 不详）。
- **模型**：多项 logistic `stage ~ 指标`（组内分别拟合），或「该指标在研究生及以后出现」的二项模型。
- **输出**：图 2（指标 × 阶段出现率热图，两组并排）；表 2（每指标的经验「阶段重心」与设计文档先验阶段相关度的方向一致率、Spearman ρ）。
- **看什么**：D2/D3/D5 类指标是否集中在研究生以后、D1 是否更早出现；方向一致率是校准先验的依据，**不是**效度证据。

### RQ3 同期比较：学生 vs 科学家「本科—研究生阶段」的行为

这是设计文档第 5 条的核心，也是**目前唯一在方法上站得住的跨组比较**。

- **取样**：只看 `stage ∈ {本科, 研究生}` 的判断；两边都截取「有该阶段证据的人」。
- **量**：① 该阶段行为指标数 / 该阶段文本量（每千字率）；② 该阶段指标出现率（0/1）。
- **模型**：`指标出现 ~ 组 + log(该阶段字数) + 学科`，逐指标；配合 Mann–Whitney + Cliff's δ。
- **输出**：表 3（同期阶段画像：6 维出现率对比 + δ + q 值）。
- **注意**：这一比较仍受「学生材料只写了本科、科学家回忆被压缩」影响，结论只能表述为**叙事差异**，不能表述为能力差异。

### RQ4 组内差异：学生内部谁的行为证据更多？

- **分层**：`award_level`（国奖 1 / 清华特奖等 2 / 年度人物 3）、`discipline`、`education`、`subset`（`cn_report` vs `cn_report_short`）。
- **模型**：负二项 `n_behavior ~ 分层变量 + log(chars)`；指标出现率用 logistic。
- **输出**：表 4（学生内部分层：每千字率、出现率、样本量）。
- **看点**：`cn_report_short`（多为答辩段落，97—500 字）与 `cn_report`（长篇报道）的差异，等于给「材料类型效应」标定一个下限。

### RQ5 文体与方法学：文本能不能支撑指标判断？

- **内容**：`text_type`、`cliche_ratio`、`first_person_share`、`honor_sentences_removed`、`n_texts`、`chars` 对「指标数 / 零指标」的解释力（负二项与 logistic，看 pseudo-R²、AIC）。
- **输出**：表 5（文体变量 → 指标数的模型比较）；并给出「一篇文本至少多少字、什么类型才可能编出 ≥1 项行为」的经验阈值。
- **价值**：这是**审稿人第一个会问的问题**，也是本研究最站得住的贡献之一：把「叙事显著性 vs 文本可观测性」分开。

### RQ6 编码质量：这套机械编码可信到什么程度？

- **已有指标**：verified 比例（3550 条中未通过 36 条，约 1%）、`shared_quote` 分布（完全复用 250、包含 139、高度重叠 1256）、`n_codes` 与 `n_behavior` 的分布、`dropped_invalid=0`。
- **需要补**：分层抽 30—50 人（国内/诺奖、长文/短文各半）做人工双编码 → 指标级 Cohen's κ（目标 ≥0.60）、level 的加权 κ（目标 ≥0.70）、引语一致率。
- **输出**：表 6（人工 vs 模型一致性；不达标指标清单）。

## 5. 统计细节

- **效应量优先于 p 值**：Cliff's δ（0/1 与计数）、OR、IRR，都带 95%CI；报告样本量。
- **多重比较**：33 项指标 × 多个分层 → 用 Benjamini–Hochberg FDR，报告 q 值；主表同时给未校正 p。
- **小样本格**：国内部分分层个位数（如 `cn_first_person` 4 人），只作描述，不进模型。
- **缺失**：不把「未出现」当 0 分（与设计文档一致），出现率分母是「该组人数」，另报「有可用文本人数」。
- **交叉验证**：n=359 时不做复杂模型；凡是要放进论文的结论，必须在两个口径（原始/去重）× 两个子样本（全体 / 排除零指标与短文）下同向。

## 6. 稳健性清单（主结果必须都过一遍）

1. 去重口径：`n_behavior_dedup` 重跑 RQ1/RQ3；
2. 排除 `shared_quote ≥ 1` 的判断；
3. 只用 `verified=1` 的判断（本已默认）；
4. 排除 15 位零指标者与 `cn_report_short`（材料最薄的一组）；
5. 排除诺奖中只靠访谈的人（`subset=nobel_interview` 且无自传者）；
6. Herbert Kroemer 一人由 `deepseek-v4.1-flash` 编的（其余 `deepseek-v4-flash`）——敏感性分析里剔掉，看结论是否动；
7. 换模型重编 20 人（例如 `deepseek-v4-pro`），看指标数是否系统性偏移（编码者稳健性）；
8. FDR 校正前后结论对比。

## 7. 信度方案（目前最大的缺口）

| 项目 | 做法 | 达标线 |
|---|---|---|
| 抽样 | 分层 40 人：国内 20（长/短各 10）、诺奖 20（自传/访谈各 10） | — |
| 编码者 | 研究助理 2 人独立编码；研究者仲裁 | — |
| 指标级 | 「是否出现」Cohen's κ | ≥0.60 |
| level | 1（声明）/2（行为）加权 κ | ≥0.70 |
| 引语 | 逐字命中率 | ≥0.90 |
| 模型 vs 人工 | 同批上跑同一提示词，算一致率 | κ≥0.50 才可替代第二编码员 |

不达标的指标：改锚点描述后重测，或从主分析中删除（不是改权重）。

## 8. 结论边界（写作时必须写进讨论）

- 样本全是获奖者 → 幸存者偏差，不能估预测效度；
- 国内材料是宣传文体 → 「失败—坚持—突破」是固定套路（试编码 8 篇中 7 篇如此），C30 这类指标在国内样本中区分度极低，需单列报告；
- 中英文本类型不同（第一人称自传/访谈 vs 第三人称通讯）→ 第一人称比例本身就是指标数的强预测变量，比较时必须控制；
- 机械编码未经人工信度检验 → 现阶段只能说「按此手册的机械编码显示……」。

## 10. 与 `analysis.py`（T01–T14 那套）的关系

`talent_corpus/analysis.py` 处理的是**证据级**记录：每条判断带 `anchor_stage`（1—4）、`evidence_quality`（1—3）、`evidence[].life_period`（P1—P6）、`coder` 字段，并与 `model_params.evaluate()` 的阶段权重相联。本数据是**人级**记录：`level`（1 声明 / 2 行为）、`stage`（5 档）、`verified`，没有锚点与质量分。

两者不能直接互换：把 level 当 anchor 会伪造出一个「25/50/75/100 分」。所以：

- 现在这套数据 → 用 `person_analysis.py`（待写）；
- 若要做「得分 + 阶段权重」式的模型验证 → 需要另跑 `code` 子命令产出证据级记录（T 指标或 C 指标带锚点），那是另一条数据线。
