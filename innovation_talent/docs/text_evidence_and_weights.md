# 文本证据能为权重提供什么

模型的指标权重由三部分相乘得到（见 `talent_corpus/model_params.py`）：

    指标原始分量 = 证据系数（A/B/C）× 阶段相关度 s1–s4 × 调整倍数
    指标总权重   = 类别权重（类别 × 阶段，DEF_DM）× 类内占比

文本证据编码（手册 1.0）回答的是“某项行为能不能在材料中被看到、出现在什么情境和什么阶段、是否进入了创造过程”，**不直接给出权重**。它能检验或修正其中的一部分，有一部分无能为力。

## 能检验的

| 权重成分 | 文本里看什么 | 用法 |
|---|---|---|
| 阶段相关度 s1–s4 | 每项指标的行为证据出现在哪个学段（education_stage）。例如 C11“对兴趣的反复返回”的先验是 (1, .8, .5, .4)，即越早越重要；如果证据集中在博士和职业期，就与先验不符 | 在不同学段的人数比例与先验方向是否一致，不一致的指标交专家复议 |
| 指标是否进入创造过程 | 行为证据中 P3（同一事件有问题、行动、后续变化）和“创造情境：明确”的比例 | 比例高的指标，说明它在叙事中确实参与了创造过程；比例长期为零的指标，或者文本看不到，或者与创造过程关系弱 |
| 指标能否被文本测量 | 人工双编码的 kappa，以及证据中“行为”与“声明”的比例 | 决定该指标能不能用文本证据计分；这是测量问题，不是权重问题 |

## 不能检验的

1. **出现得多不等于重要**。宣传稿有固定写法，“受挫—坚持—突破”在 8 段国内文本中出现了 7 次，“读了多少文献”“熬了多少夜”也是常见素材。出现频率首先反映写作套路，不能换算成权重。
2. **样本都是成功者**。特奖、国奖、诺奖得主都是按结果选出来的，组内看不到“具备该特征却没有成功”的人，因此算不出某项特征对成功的预测力。要估计这一点，需要不按结果选样的对照组（例如同院系的普通研究生），或者追踪后续结果。
3. **类别权重 DEF_DM 是理论与专家先验**，文本只能提示“某类在某阶段几乎看不到证据”，不能给出 28 还是 20 这样的数值。

## 建议做法

- 先把文本证据整理成“经验支持表”：指标 × 学段，列出出现人数、行为证据比例、P3 比例、创造情境明确的比例，并按诺奖本人自述、国内报道分开统计。
- 用这张表核对 s1–s4 的方向，以及证据系数 A/B/C 是否需要下调（例如某指标在所有材料中都只有声明、没有行为）。
- 权重数值仍由理论和专家判断确定（可用德尔菲法或层次分析法），专家评议时把这张表作为依据之一。
- 手册的 T01—T14 与模型的 C01—C33 不是一一对应，需要先建立对照表，文本证据才能落到具体权重上。
